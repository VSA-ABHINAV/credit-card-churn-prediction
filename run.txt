# Credit Card Churn Prediction — Run Commands

## Prerequisites
cd "D:\Program files\python files\ML training\Credit card"
pip install -r requirements.txt

---

## Option 1: Web Dashboard + REST API (Recommended)
# Starts both the API and the web UI on port 8000
uvicorn src.api:app --reload --host 0.0.0.0 --port 8000

# Then open in browser:
#   Dashboard:  http://127.0.0.1:8000/
#   API Docs:   http://127.0.0.1:8000/docs

---

## Option 2: CLI Batch Prediction (No server needed)
# Score a CSV file and save results
python src/predict.py --input data/BankChurners.csv --output predictions.csv

# Use your own CSV (must have the 19 required columns)
python src/predict.py --input your_customers.csv --output scored_customers.csv

---

## Option 3: API Only (For developers)
# Start API server
uvicorn src.api:app --reload --host 0.0.0.0 --port 8000

# Test endpoints (in another terminal):
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/model-info

# Single prediction
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"Customer_Age":45,"Gender":"M","Dependent_count":3,"Education_Level":"High School","Marital_Status":"Married","Income_Category":"$60K - $80K","Card_Category":"Blue","Months_on_book":39,"Total_Relationship_Count":5,"Months_Inactive_12_mon":1,"Contacts_Count_12_mon":3,"Credit_Limit":12691.0,"Total_Revolving_Bal":777,"Avg_Open_To_Buy":11914.0,"Total_Amt_Chng_Q4_Q1":1.335,"Total_Trans_Amt":1144,"Total_Trans_Ct":42,"Total_Ct_Chng_Q4_Q1":1.625,"Avg_Utilization_Ratio":0.061}'

# Batch CSV upload
curl -X POST http://127.0.0.1:8000/predict/batch \
  -F "file=@data/BankChurners.csv" \
  --output scored.csv
